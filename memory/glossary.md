# Glossary

## Preferenze & Workflow

| Regola | Dettaglio |
|--------|-----------|
| Git commit post-design | Ogni volta che si completano modifiche a file di design, eseguire un commit su git. Questo vale per qualsiasi tipo di file di design: `.fig`, `.sketch`, `.psd`, `.ai`, `.svg`, file UI/UX, componenti grafici, ecc. |
